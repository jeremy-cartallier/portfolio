## Objectif

Explorer Next.js dans un cas concret, en travaillant la navigation, le rendu de listes et l'intégration de données distantes.

## Ce que ce projet démontre

- Mise en place d'une application React structurée avec Next.js
- Consommation d'une API externe et restitution claire des informations
- Travail sur l'interface avec Tailwind pour obtenir un rendu simple et efficace
